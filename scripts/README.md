# Скрипты проекта

## compile-extensions.js

Автоматический скрипт компиляции всех расширений и темы перед сборкой приложения.

### Назначение

Этот скрипт решает проблему нестабильного попадания компонентов из расширений в production bundle. Он гарантирует, что:

1. Все расширения скомпилированы перед сборкой приложения
2. Папки `dist` очищаются перед компиляцией для чистоты сборки
3. Проверяется успешность компиляции каждого модуля

### Использование

#### Автоматический запуск

Скрипт автоматически запускается при выполнении `npm run build` через `prebuild` hook в `package.json`:

```bash
npm run build  # Автоматически скомпилирует расширения перед сборкой
```

#### Ручной запуск

Можно запустить скрипт вручную:

```bash
npm run compile:extensions
# или
node scripts/compile-extensions.js
```

### Что делает скрипт

1. **Компилирует тему** `themes/tech` (если существует)
2. **Компилирует все расширения** из папки `extensions/`:
   - Проверяет наличие `package.json` и скрипта `compile`
   - Очищает старую папку `dist`
   - Выполняет `npm run compile`
   - Проверяет, что `dist` создана и не пуста

### Обработка ошибок

- Если компиляция какого-либо модуля завершилась с ошибкой, скрипт остановится с кодом выхода 1
- Все ошибки выводятся в консоль с понятными сообщениями
- Успешные компиляции отмечаются зеленым цветом

### Зависимости

Скрипт использует только стандартные модули Node.js:
- `child_process` для выполнения команд
- `fs` для работы с файловой системой
- `path` для работы с путями

### Примечания

- Скрипт работает в Windows и Unix-подобных системах
- Порядок компиляции расширений детерминирован (сортировка по имени)
- Скрипт проверяет наличие скрипта `compile` в `package.json` перед компиляцией

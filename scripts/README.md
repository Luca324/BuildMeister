# Скрипты экспорта и импорта данных EverShop

Этот набор скриптов позволяет экспортировать и импортировать данные из/в базу данных EverShop.

## Установка зависимостей

Сначала установите необходимые зависимости:

```bash
npm install
```

## Настройка подключения к БД

Создайте файл `.env` в корне проекта со следующими переменными:

```env
# Настройки подключения к базе данных
DB_HOST=localhost
DB_PORT=5433
DB_NAME=postgres
DB_USER=postgres
DB_PASSWORD=qwerty1234
DB_SSLMODE=disable
```

Для Docker окружения используйте:
```env
...
```

## Использование

### Экспорт данных

Для экспорта всех данных из БД в CSV файлы:

```bash
npm run db:export
```

Или напрямую:
```bash
node scripts/export-data.js
```

Скрипт создаст папку `data-export` с CSV файлами:
- `settings.csv` - настройки магазина
- `categories.csv` - категории товаров
- `attributes.csv` - атрибуты товаров
- `attribute_options.csv` - опции атрибутов
- `collections.csv` - коллекции товаров
- `products.csv` - товары
- `product_categories.csv` - связи товаров с категориями
- `product_collections.csv` - связи товаров с коллекциями
- `product_attribute_values.csv` - значения атрибутов товаров
- `export-info.json` - метаинформация об экспорте

### Импорт данных

Для импорта данных из CSV файлов в БД:

```bash
npm run db:import
```

Или напрямую:
```bash
node scripts/import-data.js
```

Скрипт:
- Ищет CSV файлы в папке `data-export`
- Импортирует данные с обработкой конфликтов (обновляет существующие записи)
- Обновляет последовательности (sequences) для автоинкрементных полей
- Показывает статистику до и после импорта

## Примеры использования

### Экспорт из локальной БД
```bash
# Настройте .env для локальной БД
DB_HOST=localhost
DB_PORT=5433
DB_USER=postgres
DB_PASSWORD=mypassword

# Экспортируйте данные
npm run db:export
```

### Импорт в Docker контейнер
```bash
# Настройте .env для Docker
DB_HOST=db
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=password

# Импортируйте данные
npm run db:import
```

### Экспорт с кастомными настройками
```bash
# Переопределите настройки через переменные окружения
DB_HOST=production-server.com DB_PORT=5432 npm run db:export
```

## Структура экспортированных данных

### Настройки (settings.csv)
- `name` - название настройки
- `value` - значение настройки
- `created_at`, `updated_at` - временные метки

### Категории (categories.csv)
- `category_id` - ID категории
- `name` - название категории
- `url_key` - URL ключ
- `is_active` - активна ли категория
- `sort_order` - порядок сортировки
- `created_at`, `updated_at` - временные метки

### Товары (products.csv)
- `product_id` - ID товара
- `sku` - артикул товара
- `name` - название товара
- `description` - описание
- `price` - цена
- `weight` - вес
- `is_active` - активен ли товар
- `created_at`, `updated_at` - временные метки

И так далее для остальных таблиц...

## Устранение неполадок

### Ошибка подключения к БД
Убедитесь, что:
- БД запущена и доступна
- Правильно настроены переменные окружения в `.env`
- У пользователя есть права на чтение/запись в БД

### Ошибка "relation does not exist"
Некоторые таблицы могут отсутствовать в БД - это нормально, скрипт автоматически пропустит их.

### Проблемы с кодировкой
Убедитесь, что БД использует UTF-8 кодировку для корректного отображения данных.
